# CNN 기반 반도체 웨이퍼 맵 결함 패턴 분류 및 인터랙티브 검사
## 가천대학교 산업공학과 · InFact 교내 학회 프로젝트

### 연구 개요
반도체 웨이퍼 테스트 이후 도출되는 52×52 Die Map을 이용해 단일 결함의 공간 패턴을 분류하는 CNN 기준 모델을 설계하고, 검사자가 개별 다이 상태를 확인할 수 있는 Flask 웹 인터페이스를 구성했습니다. SEM에서 미세한 물리적 결함을 검출하는 연구가 아니라, 테스트 단계에서 기록된 다이의 PASS/FAIL 분포를 분석하는 프로젝트입니다.

### 데이터 및 전처리
혼합 결함 30,000개를 제외하고 정상 + 단일 결함 8종, 총 8,015개를 우선 대상으로 삼았습니다. 이후 Die 값 3이 기록된 105개 샘플을 검증 불가능한 입력으로 분리하여 7,910개를 기준 코호트로 정의했습니다. 전체 원본 38,015개는 별도로 보존하고 분석 단계에서만 필터링했습니다.

### 구현
Python / NumPy로 데이터를 가공하고, scikit-learn으로 층화 분할과 학습 집합의 클래스 가중치를 처리했습니다. TensorFlow/Keras에서 Conv2D–MaxPooling 구조의 CNN과 Global Average Pooling, Dropout, 9개 노드 Softmax 출력층을 정의했습니다. Flask API는 원본 라벨, Die 상태 개수, 준비된 모델이 있는 경우에 한정한 예측 응답을 제공하도록 구성했습니다. 웹 화면은 HTML Canvas와 JavaScript로 Die별 상태와 Hover 좌표를 표시합니다.

![CNN 구조](../assets/diagrams/cnn_architecture.svg)

### 확인된 결과와 미확인 결과
데이터셋 필터링 수치와 코드 구조, 테스트는 확인했습니다. 그러나 최종 Accuracy, Macro-F1, 혼동행렬, 실제 수율 개선률은 학습 및 실측 자료가 없어 결과로 기록하지 않았습니다.

### 산업공학적 의미
웨이퍼의 불량 비율은 하나의 수치이지만, 공간 패턴은 다이 불량이 어떻게 모여 있는지에 대한 추가 정보를 담습니다. 이는 품질 검사 자동화, 수율 분석, 제조 데이터 품질 관리로 이어질 수 있습니다. 실제 공정 원인을 확인하려면 설비, Lot, Recipe, 센서 로그와 연결한 후속 검증이 필요합니다.
