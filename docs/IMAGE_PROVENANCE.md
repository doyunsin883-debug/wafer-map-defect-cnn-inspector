# Image provenance and missing-media policy

Every visual in the GitHub README is backed by an actual committed file. We do not intentionally leave image links pointing at nonexistent assets.

| Visual currently in repository | Origin / description |
|---|---|
| assets/hero_wafer_inspector.png | Earlier project hero using wafer-pattern examples |
| assets/wafer_class_atlas.png | Nine representative source-class maps from the original local archive |
| assets/figures/dataset_filtering.png | Actual audit counts of the provided archive |
| assets/figures/class_distribution.svg | Vector plot of actual final class counts |
| assets/diagrams/system_pipeline.svg | Schematic workflow, not a factory-connected deployment |
| assets/diagrams/cnn_architecture.svg | Diagram of layers from the Python source |
| assets/diagrams/inspection_interface_schematic.svg | **Illustration**, not a running TensorFlow prediction screenshot |
| assets/diagrams/infact_announcement_transcript.svg | **Transcription diagram**, not the original user-provided campus screenshot |

The complete separate local package also contains original screenshots of the browser-rendered interface, author-supplied InFact announcement/profile, and image renderings of the historical PDF report. Those files have not all been transferred to this GitHub remote. Their absence must never be disguised by synthetic photographic evidence.

**Source dataset**: [MixedWM38/WaferMap](https://github.com/Junliangwangdhu/WaferMap).
